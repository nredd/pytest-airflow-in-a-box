`piab` is now a supported alias: the wheel ships a `piab` mirror package (attrs-style thin re-export shims, guarded by a sync test) so `from piab.matchers import succeeded` resolves the real objects with full static types, and a PEP 562 `__getattr__` plus `TYPE_CHECKING` re-exports make `import pytest_airflow_in_a_box as piab` attribute access work and type-check too. Docs and the `tests/enduser` consumer suite use the short spelling.
