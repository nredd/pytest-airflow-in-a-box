New default-on smoke check `test_no_runtime_varying_dag_args` flags runtime-varying values (`datetime.now()`, `uuid4()`, `random.*`, `pendulum.now()`, ...) passed to Dag or task constructors, which inflate the serialized Dag version on every parse. Disable with `airflow_forbid_runtime_varying_dag_args = false` or `airflow_smoke_disable`. Adapted from Apache Airflow's Dag version inflation checker (see `PROVENANCE.md`).
